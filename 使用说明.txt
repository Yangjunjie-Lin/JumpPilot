JumpPilot 1.4 · 跳一跳视觉助手
============================

这是一个 Windows 10/11 64 位本地视觉工具，针对示例中的经典紫色棋子、
圆形/四边形顶面及部分带纹理、文字、内圈装饰的道具设计。
它不读取游戏内存，不接入游戏账号，不发送网络数据。
不是手机微信里的小程序；手机必须通过可鼠标操作的投屏等方式运行，
该场景没有实测，也没有提供 Android ADB 或 iOS 控制。

快速开始
--------
1. 解压完整压缩包，双击 JumpPilot-v1.4.exe。不需要安装 Python，也不需要管理员权限。
   请启动这个带版本号的新程序；原来的 JumpPilot.exe / v1.2 / v1.3 不包含本次更新。
2. 启动后先显示随附的离线示例图，不会自动按压。
3. 打开电脑上的跳一跳游戏。点击“框选游戏”，拖出完整竖屏游戏区域。
   后续始终保持相同裁剪边界；缩放按画面宽度归一化，不可任意改变裁剪方式。
4. 把助手窗口移到游戏旁边，不要遮挡游戏。确认绿色 S 是当前平台的顶面中心、
   黄色 T 是下一平台的顶面中心，青色 A 是棋子实际落脚点。
   可选“标落脚 A / 标当前顶心 S / 标下一顶心 T”后点击左图修正。
5. 选“设按压点”，在预览图的游戏空白区域点一下，避开暂停、标题栏、分享按钮。
6. 核对 k、b、微调系数。勾选“已校准参数，并核对游戏区域和按压点”。
   先点“单步试跳”，有 3 秒倒计时。初始参数仅供试验，不保证第一次成功。
7. 校准可靠后，设置“本轮步数”，再点“开始自动跳”：
   填 0 = 无限跳，不因步数自动结束；填正整数 = 运行指定次数，已取消 30 步上限。
   默认仍是 5 步。“单步试跳”始终只运行一次，不受这里的 0 影响。
   无限模式仍会因人工停止或安全异常结束，低置信度会暂停等待确认。
   如需自适应校准，先按下文设置分数区域，确认读分正确后再勾选“启用本轮学习”。
8. 按 Esc、点击停止，或把鼠标移到整个虚拟桌面的最左上角，可中断。
   工具在异常、取消或退出时都会尝试释放鼠标左键。

无限模式与人工确认
------------------
* 运行进度显示“已执行 N/∞ 次按压”；这是按压计数，不是成功落地计数。
* 无限模式不代表无人值守或自动重开：游戏结束、识别失败等安全异常仍会停止。
  停止后需核对画面、重新勾选运行确认，再点“开始自动跳”；不会自行恢复。
* “自动阈值 %”默认 84，可设置 0–100。有效置信度低于此值时，
  程序不按压，显示当前帧并等待你核对 S/T/A 点位。
* 可以选择相应标点模式修正当前帧，也可以填写“本帧人工评分 %”，
  点“应用本帧评分”，然后点“确认本帧 / 继续”。也可不改分数，直接确认。
* 算法原始评分与人工评分分别显示；人工修改不是重新训练算法，也不是成功率。
  人工确认会放行当前帧，即使其评分仍低于阈值；但不会绕过时长、窗口和画面检查。
  仅应用评分不会在等待确认时自动继续，必须明确点击确认按钮。
* 确认后重新聚焦游戏，倒计时 3 秒并复核画面。画面已变化则本次确认失效并停止。
  下一跳必须重新识别，人工评分、确认及修正坐标不会沿用。
* 等待确认时仍可停止 / Esc；等待期间没有鼠标按住。
* 启动前的手动标点仍只允许“单步试跳”；自动过程中可以暂停并修正本帧后继续。

v1.4 新增：特殊道具顶面定位
-------------------------
* 同时识别当前脚下平台与下一平台的顶面。S/T 的位置来自可落脚面的边界，
  不是道具整个包围框、侧面、阴影或内部文字/图案的重心。
* 对带文字、条纹、棋盘纹理、偏心图案和小装饰的四边形顶面，增加独立边缘检测、
  四边支撑检查与透视四角对角线交点计算。四角不对称时不用简单的四点平均值。
* 保留圆形道具的椭圆顶面拟合，并合并同心轮廓。嵌套小图案被外层可信顶面包围时，
  不作为另一个平台；强纹理边缘断裂时尝试从局部直线恢复可见顶面。
* 当前平台会结合落脚点附近的图像查找，排除棋子本身遮挡的边缘，使用其余可见边缘
  或圆弧恢复 S。不会直接把 A 复制成“已识别的当前平台中心”。
* 四条实际边必须有足够图像证据；断边恢复的下一目标评分最多 79%，在默认 84% 阈值下
  暂停请求人工确认。降低用户阈值会改变这一行为，请谨慎使用。
  S 无法识别时明确显示“未识别”，综合评分最多 65%；可手动标 S 并确认这一帧。
  严重遮挡、画面裁切或完全找不到下一目标时仍停止，不凭空补出落点。
* 绿色细线和面板显示 S→T 顶心间距；红色线和按压计算使用 A→T 实际起跳距离。
  上一跳落偏时 S 和 A 不重合，这是正常的：从 A 计算才能补偿已有落脚误差。
  既有 k/b 标定及学习公式仍使用实际起跳距离，不把两种距离混用。
* 可以单独手改 S，不影响 A/T 的坐标与本次按压距离。手改任一点均清除本帧人工评分
  和确认状态；手改 A 会清除原来 S 的定位，因为原来的脚下平台关系已不可信。
* 这些是几何适配，不是对所有游戏道具的通用语义识别，也不包含弹簧/传送/移动平台
  的特殊物理模型。异形、强遮挡、重叠和特殊运动规则仍需人工处理。
* 随附 prop-demo.png / prop-demo-analysis.png 是人工构造的离线几何示例，
  用于说明 S/T/A 与偏心纹理；并非你的真实游戏截图，也不是成功率证明。

保留：得分 + 落点自适应校准
--------------------------
1. 在“03+ 得分与落点自适应校准”点击“框选分数”，然后在左图依次点击
   数字区域的左上角、右下角。只包括完整数字，四周留一点空白，不要带上按钮、
   “得分”等文字或其他图标。该区域必须在游戏画面顶部 30% 内。
   紫色虚线框表示分数区域；“测试读分”只分析当前预览，实时画面变化后先刷新。
2. 核对“游戏得分”的数值确实正确。它与“有效置信度”不是同一个东西。
   本地数字模板支持经典方块数字和若干常见字体，不是通用 OCR。
   数字不完整、混有图标或字体不支持时显示不可用，不使用猜测值来学习。
3. 勾选“启用本轮学习”，再勾选正常的运行确认并启动。
   默认关闭学习；每次重启或重新框选游戏都不会自动启用。
   同一轮至少需要 3 次方向一致的可靠反馈，单次试跳不会直接改参；
   重新启动一轮会清空本轮反馈批次，不会把旧场景反馈混入新场景。
4. 每跳前后分别读取两次分数。读数稳定且质量足够、可信加分为 1–100，
   才可能进入学习。额外奖励多少不决定调整幅度，也不把加分等同于正中靶心。
5. 程序跟踪“刚才的目标平台”在落地画面中的位置，检查轮廓、可见边缘和颜色。
   这允许镜头平移；不会直接把跳前目标坐标与滚动后的棋子坐标相减。
   实际落脚点相对落地平台中心，沿跳跃方向偏短则增大时长倍率，偏远则减小。
6. 需连续 3 次可靠反馈方向一致才更新一次。每次倍率最多变化 2%，
   本轮累计不超出启动倍率的 ±15%，且仍受倍率 0.5–1.5 和按压时长限制。
   中心附近 4 标准像素内不调整；横向偏离过大、匹配不唯一、时长抖动、
   原始识别评分不足或人工改点时不自动学习。失败/不确定反馈会清空当前批次。
7. 学习只调整“时长微调”倍率；k、b 不自动改变，因为一次落点不能同时确定
   两个独立参数。需要重建距离—时长模型时，仍用成功样本拟合 k / b。
8. 面板显示每跳反馈、偏差、可靠反馈数及倍率变化；未通过校验时显示不学习原因。
   得分读不到/不增长时保留原参数；稳定读到得分下降或重置时停止自动跳。
9. 停止后可点“撤销本轮学习”恢复本轮起始倍率，不覆盖后来手动修改的 k、b。
   学到的倍率只在内存中生效；确认效果后点“保存参数”才会保留到下次启动。
   不会自动覆盖你的标定文件，也不会保存学习启用开关。
10. 重新框选游戏会恢复默认分数区域并关闭学习，需重新核对分数框。
    学习匹配只支持同尺寸画面的平移，不保证支持镜头缩放、旋转、动画换皮等情况。

保留：后期多平台识别
------------------
* 以棋子当前落脚点 A 为参照，排除脚下的平台、同高度/下方平台和不符合跳跃方向的图形。
* 只在上方最近一层候选里选下一目标 T，不按整屏最高形状评分选择远处平台。
  更高、更远的后续平台不会加入本次距离，也不会因为轮廓更清晰而取代较近候选。
* 同一层左右都有候选时降低置信度，暂停请求人工确认，不假定一定往某侧跳。
* 本规则针对经典向上推进的布局，不会读取关卡路线；岔路、重叠或特殊关卡仍需人工确认。

测算原理
--------
实际起跳距离 d = sqrt((Tx-Ax)^2 + (Ty-Ay)^2)
顶心间距 d中心 = sqrt((Tx-Sx)^2 + (Ty-Sy)^2)，仅供平台几何核对
标准距离 d标准 = d × 540 / 当前框选画面宽度
按压时长 t(ms) = 时长微调 × (k × d标准 + b)

k 的单位是 ms/标准像素；b 是固定延迟补偿；微调是时长倍率，不是物理压力。
普通鼠标不会传递可控的按压力度。跳一跳通常用按压时长模拟蓄力。
若具体游戏确实读取硬件压力，本工具不能控制该压力，需要不同输入设备与方案。

默认 k=2.7、b=0、微调=1，只是未经校准的启动值。
示例截图识别约 A=(168,623)、S=(167,622)、T=(394,494)，实际起跳距离约 261 px；
按默认参数试算约 707 ms。此时间不代表游戏的真实正确时间。
安全范围默认 80–1800 ms；超界会拒绝执行，而不是悄悄截断成错误时长。

如何校准
--------
* 首先单步试跳。跳短则稍微增大 k；跳远则稍微减小 k，例如每次调整 3%–5%。
* 只有你确认落在平台中心附近的一跳，才添加为“成功样本”。
  如果工具执行过单步，样本对话框会预填最近一次按压的跳前距离、宽度和指令时长。
  注意：按压次数不等于成功次数，工具不会替你假定某次跳跃成功。
* 至少两条不同距离样本才能拟合 k、b，标准距离相差至少 30 px。
  建议积累 3–5 条覆盖短、中、长距离的成功样本，再点“拟合 k / b”。
  两点拟合的误差可以为零，但不能证明模型真实准确。
* “保存参数”会在程序旁边写 jump-pilot-settings.json。
  保存的只有参数、样本、自动置信度阈值和分数区域，不保存屏幕图像、窗口绑定、运行开关，
  也不保存本帧人工评分、人工确认、反馈历史或学习开关。每次启动默认仍是 5 步。
  重启、修改参数、修改点位、重新框选和每次结束后，都需要重新勾选运行确认。
* 窗口缩放使用标准宽度换算；更换游戏版本、投屏延迟或裁剪范围后重新校准。
* 如果长短距离存在系统性误差，线性模型可能不适用；不要继续增加自动步数。

识别和停止条件
--------------
* 使用经典紫色棋子的头部/身体颜色、形状找落脚点。
* 使用背景差异、纯色区域、边缘轮廓、局部直线和几何约束找平台顶面，
  检查可见边界并筛除不符合顶面结构的侧面。复杂阴影仍可能造成误判，需核对。
* 圆形平台按透视后的椭圆顶面拟合：结合平坦区域与边缘轮廓，检查拟合残差、
  方向和轮廓覆盖，并合并同心边缘，减少将圆环内圈/外圈误判为不同目标的情况。
* 显示的“识别评分”只是启发式质量评分，不是概率，也不是跳跃成功率。
* 支持向左和向右。对超出测试范围的纹理、装饰、强遮挡、特殊皮肤、小平台或多个
  候选目标不保证识别。有候选但不确定时降低评分并请求人工确认；完全找不到点位时停止。
  人工提高评分无法凭空生成缺失点位，也不能保证落地成功。
* 每一步都重新截图，等待稳定，检查识别后画面未变，再执行长按。
* 窗口移动、缩放、最小化、遮挡、失去焦点、找不到棋子/平台、
  画面运动不停止、按压后画面未变或计算时长超限，均会停止。
* 默认的“落地后检查”只确认画面还能识别。启用学习后会额外检查得分与落点，
  但这些都是视觉证据，不等于读取游戏内部状态或证明成功通关。
* 正在自动按压时不要切窗口或操作鼠标；人工确认暂停期间可以操作助手界面。
  不要把本工具用于敏感应用，也不要在无人看管时持续运行。
* 建议在主显示器使用；跨屏窗口、负坐标副屏和混合 DPI 缩放没有实测。
* 如果 Windows 拒绝输入，先确认游戏和工具均以普通权限运行；不要提权绕过。

开发者运行
----------
源代码和自动化测试随附，可审查和修改；代码未混淆。

使用 Python 3.12，在此目录运行：
    python -m venv .venv
    .venv\Scripts\python -m pip install -r requirements.txt
    .venv\Scripts\python app.py

运行测试（不发送真实鼠标输入）：
    .venv\Scripts\python -m pip install pytest
    .venv\Scripts\python -m pytest -q

只分析图片（永不按压）：
    .venv\Scripts\python app.py --analyze sample.png --output analysis.png --report analysis.json

主要文件：
    app.py          本地中文 GUI、框选、点位修正和校准样本
    vision.py       纯本地 OpenCV 视觉检测、距离和标记图
    top_geometry.py 道具顶面四角、可见边缘/圆弧恢复及嵌套图案过滤
    calibration.py  带验证的距离—时长拟合
    adaptive.py     镜头平移后的落地平台匹配、得分门控及有限幅度的倍率学习
    score_reader.py 游戏数字分数的本地模板识别（不是置信度评分）
    controller.py   有限/无限步数、人工确认、画面稳定检查和异常停止
    wininput.py     Windows 窗口绑定和可取消鼠标长按
    test_jump_pilot.py  离线测试与模拟控制测试
    test_round_review.py  圆形平台与人工确认回归测试
    test_unlimited.py     无限步数与大于 30 步的模拟运行测试
    test_learning.py      得分、落点匹配、多平台选择与学习限制测试
    test_props.py         特殊道具顶面、当前中心和人工校正测试
    conftest.py       隐藏界面的测试环境
    licenses/        随附依赖许可文本

软件为本地构建的未签名程序。如果系统拦截，不要绕过安全警告；
可以审查随附源码并使用隔离 Python 环境运行。
